# Python Starter Exercises

Introductory Python examples for type conversion, input, variables, and arithmetic.

## ✨ Highlights

- Explore conversions in `pythonProject/TypeCasting.py`.
- Follow interactive exercises in `pythonProject/input.py`.

## 🚀 Getting started

Install Python 3, open a terminal in this repository, then run:

```sh
python "pythonProject/input.py"
```

Follow the prompts in the terminal.
